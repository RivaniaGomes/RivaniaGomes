<h2> 🚀 Projetos em Destaque </h2>

### 📚 [Reading Journal Covers](https://github.com/RivaniaGomes/reading-journal-covers)
> **Automação em Python para geração de capas de livros e PDFs de impressão.**

Ferramenta CLI que automatiza a busca de capas de livros via APIs (Google Books & Open Library), faz o download e tratamento de imagens com `Pillow` e monta grids customizados em PDF prontos para impressão.

- **Tecnologias & Módulos:** `Python 3`, `Pillow`, `Requests`, `APIs REST`, `CLI / Argparse`
- **Destaques:** Processamento modular, cache de imagens existentes, manipulação de imagens e geração automática de PDF.

[📂 Ver Repositório](https://github.com/RivaniaGomes/reading-journal-covers)
